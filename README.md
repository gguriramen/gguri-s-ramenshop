# 꾸리의 라멘가게 🍜

슈의 라면가게에서 영감을 받은 작은 라멘 요리 게임입니다. Flash 없이 브라우저에서 실행됩니다.

## 실행

`index.html` 한 파일을 다운로드하여 브라우저에서 열면 됩니다. 디자인과 게임 코드가 모두 포함되어 있어 다른 파일이나 인터넷 연결이 필요 없습니다. HTML 미리보기 서비스가 JavaScript를 차단하는 경우 다운로드한 파일을 일반 브라우저에서 열어 주세요.

개발 중에는 저장소에서 다음 명령으로 서버를 실행할 수도 있습니다.

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

별도 패키지 설치는 필요 없습니다. `style.css`, `engine.js`, `game.js`를 수정한 뒤에는 `python3 bundle.py`로 단독 실행 파일을 갱신합니다. 이미 생성된 `index.html`은 빌드 없이 바로 플레이할 수 있습니다.

## 게임 방법

- 첫 방문에는 **첫 라멘 함께 만들기**로 주문 선택 → 냄비 선택 → 물 → 면 → 달걀 → 익히기 → 서빙을 연습합니다. 연습에서는 영업 시간과 손님 대기 시간이 줄지 않으며, 초록 구간에서 조리가 멈춰 면이 불지 않습니다.
- 연습은 건너뛸 수 있습니다. 완료하면 90초·0점의 새 영업을 시작하며, 이후 **게임 방법 → 첫 라멘 연습하기**로 다시 연습할 수 있습니다. 완료 기록은 브라우저에만 저장하며, 저장 기능을 사용할 수 없어도 연습과 본 게임은 동작합니다.
- 90초 동안 손님의 주문을 맞추세요. 손님은 30초 동안 기다립니다.
- 손님과 냄비를 선택하고 물 → 면 → 주문한 토핑을 넣습니다.
- 면을 넣은 뒤 6~10초 사이, 초록 구간에 손님에게 내세요.
- 정확한 주문은 100점, 연속 성공은 최대 100점의 추가 보너스를 받습니다.
- 잘못 낸 라멘은 20점, 떠난 손님은 30점 감점됩니다. 점수는 0 아래로 내려가지 않습니다.
- 재료는 키보드 1~5로도 넣을 수 있습니다. 게임 방법을 열거나 다른 탭으로 이동하면 일시 정지합니다.
- 모바일에서는 손님과 냄비를 터치하여 선택합니다. 하단 고정 바에서 선택한 냄비·손님을 확인하고 라멘을 낼 수 있습니다. 세로·가로 화면을 지원하며, 화면이 작으면 스크롤하여 플레이할 수 있습니다.

## 검증

```sh
node --test engine.test.js
```

외부 서비스, 로그인, 데이터베이스 없이 작동하며 점수는 영업마다 초기화됩니다.
