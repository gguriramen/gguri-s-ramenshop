# 꾸리의 라멘가게 🍜

슈의 라면가게에서 영감을 받은 작은 라멘 요리 게임입니다. Flash 없이 브라우저에서 실행됩니다.

## 실행

`index.html` 한 파일을 다운로드하여 브라우저에서 열면 됩니다. 디자인과 게임 코드가 모두 포함되어 있어 다른 파일이나 인터넷 연결이 필요 없습니다. HTML 미리보기 서비스가 JavaScript를 차단하는 경우 다운로드한 파일을 일반 브라우저에서 열어 주세요.

개발 중에는 저장소에서 다음 명령으로 서버를 실행할 수도 있습니다.

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

별도 패키지 설치는 필요 없습니다. `style.css`, `engine.js`, `game.js`를 수정한 뒤에는 `python3 bundle.py`로 단독 실행 파일을 갱신합니다. 이미 생성된 `index.html`은 빌드 없이 바로 플레이할 수 있습니다.

## 게임 방법

- 첫 방문에는 **첫 라멘 연습하기**로 주문 선택 → 냄비 선택 → 물 → 면 → 주문한 토핑 → 익히기 → 서빙을 연습합니다. 연습에서는 영업 시간과 손님 대기 시간이 줄지 않으며, 초록 구간에서 조리가 멈춰 면이 불지 않습니다.
- 연습은 건너뛸 수 있습니다. 완료하면 90초·0점의 새 영업을 시작하며, 이후 **게임 방법 → 첫 라멘 연습하기**로 다시 연습할 수 있습니다. 완료 기록은 브라우저에만 저장하며, 저장 기능을 사용할 수 없어도 연습과 본 게임은 동작합니다.
- 90초 동안 손님의 주문을 맞추세요. 손님은 30초 동안 기다립니다.
- 손님을 고르고 물 → 면 → 주문한 토핑을 원하는 냄비로 드래그해 넣습니다. 냄비에 놓으면 해당 냄비가 선택됩니다. 누르기와 키보드 입력도 지원합니다.
- 면을 넣은 뒤 6~10초 사이, 초록 구간에 손님에게 내세요.
- 정확한 주문은 100점, 연속 성공은 최대 100점의 추가 보너스를 받습니다.
- 잘못 낸 라멘은 20점, 떠난 손님은 30점 감점됩니다. 점수는 0 아래로 내려가지 않습니다.
- 재료는 키보드 1~5로도 넣을 수 있습니다. 게임 방법을 열거나 다른 탭으로 이동하면 일시 정지합니다.
- 잘못된 재료 입력이나 서빙은 손님 위쪽의 전용 안내 공간에서 알림으로 안내하고 해당 조작을 잠깐 강조합니다. 알림은 약 5초 뒤 사라지며, 올바른 입력으로도 해제됩니다. 알림이 떠 있어도 게임은 계속 진행됩니다.
- 서빙에 성공하면 같은 안내 공간에 완성 라멘 그림, 받은 점수, 연속 성공 횟수를 약 4초간 표시합니다. 다음 재료를 넣어도 유지되며, 오류가 발생하면 같은 위치에서 오류 안내로 바뀝니다.
- 모바일에서는 물·면·토핑을 재료 바구니에서 원하는 냄비로 끌어다 넣습니다. 초록 구간이 되면 **냄비의 라멘을 손님에게 드래그**하여 냅니다. 별도 팝업 없이 원래 손님 카드에 놓으며, 받을 친구가 강조됩니다. 헤더·시간/점수·손님·냄비·재료·비우기 버튼을 한 화면에 배치하며, 게임 화면은 스크롤하지 않습니다. 냄비 전체는 드래그 영역입니다. 손님 밖에 놓거나 터치가 취소되면 라멘은 냄비에 남습니다. 조리와 손님 대기 시간은 드래그 중에도 흐릅니다.
- 모바일 튜토리얼 마지막 단계도 드래그로 서빙합니다. PC에서는 기존 서빙 버튼을 사용하며, 키보드·보조 기술을 위한 서빙 버튼도 유지합니다. 세로·가로 화면을 지원하며, 가로 화면에서는 손님과 주방을 좌우에 배치합니다. 튜토리얼 안내도 화면 안에 표시합니다.

## 검증

```sh
node --test engine.test.js
```

기본 게임은 외부 서비스 없이 작동합니다. 시작할 때 아이디를 입력하며 현재 영업 점수는 매번 초기화하고, 아이디별 최고 점수와 전체 플레이 시간은 이 브라우저에 보관합니다. 친구들과 전체 랭킹을 공유하려면 Supabase 연결이 필요합니다.

모바일 상단 로고는 제공된 꾸리라멘 로고이며 영문 표기는 **KKURI RAMEN**입니다. 환영 문구와 꾸리 그림은 **게임 방법** 상단에서 볼 수 있습니다. 손님 이름과 냄비 번호는 모바일 화면에서 생략하며, 접근성 이름에는 유지합니다.

모바일에서는 손님 카드 위에 높이가 일정한 작은 안내 공간을 항상 확보합니다. 상단 시간·점수와 재료 바구니를 크게 표시합니다. 오류·서빙 성공·튜토리얼은 이 공간을 공유하며, 주방 높이를 줄여 알림이 조작부를 가리지 않도록 합니다.

재료를 끌면 그림이 손가락을 따라 움직이고 놓을 냄비가 강조됩니다. 냄비 밖에 놓거나 터치를 취소하면 재료는 들어가지 않습니다. 물·면 순서, 중복 재료와 토핑 제한은 드래그에도 동일하게 적용되며, 첫 라멘 연습에서도 재료 드래그를 배울 수 있습니다.

안내 알림 오른쪽에는 닫기 버튼 대신 점수 변화(`+100점`, `−20점` 등)를 테두리 상자에 크게 표시합니다. 획득 점수는 녹색, 감점은 갈색 계열이며, 감점 없는 입력 안내에는 점수 상자를 표시하지 않습니다. 여러 손님이 동시에 떠나면 해당 감점을 합산해 표시합니다.

첫 진입 화면은 ‘꾸리와 첫 라멘을 만들어 볼까요?’라는 제목과 큰 ‘첫 라멘 연습하기’ 버튼으로 연습을 먼저 안내합니다. ‘바로 영업하기’는 작은 보조 링크로 표시합니다. 연습 완료 후 재방문하면 ‘영업 시작하기’를 메인 버튼으로, ‘첫 라멘 연습하기’를 보조 버튼으로 표시합니다.

첫 토끼 주문을 포함한 모든 주문은 달걀·파·차슈 중 동일한 확률로 무작위 선택됩니다. 연습에서도 주문을 고정하지 않으며, 실제 주문에 맞춰 안내 문구와 강조되는 토핑 버튼이 바뀝니다.

연습 중 게임 방법을 열면 ‘계속 연습하기’로 현재 단계를 이어가거나 ‘영업 시작하기’로 연습을 끝내고 90초·0점의 새 영업을 시작할 수 있습니다. 실제 영업 중 게임 방법에는 ‘계속 플레이하기’와 ‘첫 라멘 연습하기’를 표시합니다.

## 내 정보와 랭킹

시작 화면에서 아이디를 입력합니다. 오른쪽 위 다시하기 버튼 옆의 동그란 사람 버튼을 누르면 아이디·최고 점수·전체 플레이 시간을 보고, 하단에서 최고 점수 순 또는 플레이 시간 순으로 친구들의 랭킹을 확인할 수 있습니다. 연습과 일시정지 시간은 누적하지 않습니다. 공용 랭킹 연결 전에는 개인 기록만 기기에 저장하며 전체 랭킹의 준비 상태를 표시합니다. 연결 방법과 저장·계정 범위는 [SOCIAL_SETUP.md](SOCIAL_SETUP.md)에 있습니다.
